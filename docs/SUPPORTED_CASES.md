# Supported Cases

This document prevents the app from pretending to support scenarios the current model cannot justify.

## Initial Target
- Korean residential apartments,
- above-ground units,
- natural ventilation through windows/doors,
- desktop web workflow.

## Planned Limited Support
Lower confidence until validated:
- corridor-style apartments,
- very high-rise units,
- mixed-use buildings,
- irregular L/U-shaped footprints.

## Not an Initial Target
- detailed basement/semi-basement airflow,
- mechanical HVAC simulation,
- CFD-grade turbulence,
- detached houses with complex roofs,
- smoke/fire safety simulation.

Unsupported cases should produce explicit limitations/warnings rather than fabricated precision.
